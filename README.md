# 聖經概覽｜互動網站

這個網站依據你提供的 Excel《聖經概覽__D20260521.xlsx》製作。

## 使用方式

1. 解壓縮 ZIP。
2. 直接以瀏覽器開啟 `index.html`，即可閱讀；無須額外安裝軟體或建立 Firebase 資料庫。
3. 若在 GitHub Repository 使用 Cloudflare Pages，將**整個資料夾的檔案**放到儲存庫根目錄（`index.html` 必須在根目錄）。
4. Cloudflare Pages → Workers & Pages → Create → Pages → Connect to Git → 選擇 GitHub Repository。
5. Framework preset 設為 **None**；Build command **留空**；Build output directory 設為 `/`（或依 Cloudflare Pages 介面設定為儲存庫根目錄）。完成部署後即可使用。

此網站使用靜態 HTML + CSS + JavaScript，不需要環境變數、API Key、Node.js、Firebase、Cloudflare Worker 或外部資料庫。

## 主要功能

- **25 個工作表完整匯入**，保留原始文字、註解、資料順序、內嵌圖片與來源檔案。
- **家譜內的原始超連結**：點擊以綠色標示的人名可跳到相應家譜／人物位置；支援原始 Excel 的「命名範圍」連結。
- **手機／桌機不同閱讀方式**：資料表可選卡片或完整表格；家譜可選文字閱讀或有原始相對位置與連接線的圖譜。
- **深色／淺色模式**，會記住選擇；全站關鍵字搜尋與各表內的即時篩選。
- 可點擊圖片放大；可點擊含註解的儲存格閱讀 Excel 的原始註記。
- 無須伺服器，純靜態部署。

## 檔案

- `index.html`：首頁及網站結構。
- `styles.css`：網站外觀、手機響應式設計、深淺色樣式。
- `app.js`：互動導覽、家譜跨頁、搜尋、圖像、縮放及篩選。
- `data/workbook.js`：供瀏覽器離線讀取的完整資料（**不需要 fetch**）。
- `data/workbook.json`：相同的原始轉換資料，便於之後維護或編程使用。
- `data/integrity.json`：Excel 原始檔 SHA-256 與總量稽核資訊。
- `assets/images/*`：原始 Excel 內嵌圖像，沒有重繪。
- `assets/board-*.svg`：由原始儲存格框線／背景色提取的圖譜底圖（用來維持原始關係結構）。
- `original/聖經概覽__D20260521.xlsx`：完整未修改的來源 Excel。

## 資料忠實性與限制

本網站沒有改寫原始資料。**原始 Excel 是最終的準確依據**。網站的分類、文字閱讀模式、表格欄名組合、圖片排列和網站內的導覽文案屬於介面設計，不是對原始資料的修訂。

- Excel 裡的複雜合併儲存格與框線，在「關係圖譜」模式以相對位置和底圖盡可能保存；在手機「文字閱讀」模式則只按照儲存格位置排序，**不代表人物親屬關係**，不能用來推斷家譜分支。請切換「關係圖譜」判讀關係。
- 一些原始範圍包含大段留白或以圖片繪製；對於純圖片的頁面，網站顯示其內嵌原圖。
- Excel 自動篩選、公式重新計算、VBA 與 Excel 編輯操作不在本靜態網站範圍；來源檔案保留。
- 原始 Excel 中若存在已失效的內部連結，網站不會自行猜測一個新位置，而會顯示提示。
- 修改 Excel 後若要更新網站，必須重新匯出 `data/workbook.js` 和相關資源；編輯網站檔案不會反向更新 Excel。
